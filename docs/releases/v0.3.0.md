## 星笺 v0.3.0 · 首个 Android Release

星笺 / Arcana Notes 是一款 Flutter Material 3 深色塔罗应用。

- 完整 78 张原创卡面、正逆位牌义与 9 种图形牌阵。
- 每日一牌、占卜、牌库和本地日记；支持长按多选删除及撤销。
- OLED 纯黑页面，底栏与组件使用系统动态配色。
- 中、英、日语言切换；左右滑动或点击底栏切换页面并保留状态。
- DeepSeek 官方与 OpenCode Go 接入、独立密钥和 AI 解读；设置提供 GitHub 仓库入口。

**安装：** 不确定架构时下载 `universal.apk`；大多数现代 Android 手机可选 `arm64-v8a.apk`，体积更小。`armeabi-v7a.apk` 用于 32 位 ARM 设备，`x86_64.apk` 用于相应模拟器或设备。请下载 APK，GitHub 自动生成的 Source code 压缩包不是安装包。

APK 在 GitHub Actions 中以 release 模式构建，使用项目专用签名，并通过 APK 签名与包信息检查。校验值见 `SHA256SUMS.txt`。应用包名为 `io.github.clcty.arcana_notes`；后续更新将沿用同一签名。

验证：21 项 Flutter 测试、2 项本地 Web 转发测试及静态检查；尚未进行 Android 真机测试。系统壁纸取色需要设备支持。AI 需要用户自己的 API Key，调用可能收费；OpenCode Go 的用途与权限取决于服务方规则。日记仅存本地，卸载或清除应用数据会移除记录。此版本的塔罗解读用于自我反思，不保证事件预测。

## Arcana Notes v0.3.0 · First Android Release

A dark Flutter Material 3 tarot app featuring 78 original card illustrations, upright/reversed meanings, nine graphical spreads, a daily card, local journal, selection/delete/undo, OLED backgrounds, system dynamic colors, Chinese/English/Japanese, horizontal swipe navigation, and optional DeepSeek / OpenCode Go readings.

**Install:** Choose `universal.apk` if unsure. Most modern Android phones can use the smaller `arm64-v8a.apk`; `armeabi-v7a.apk` is for 32-bit ARM devices, and `x86_64.apk` is for matching devices/emulators. The automatic Source code archives are not installers.

Built in release mode on GitHub Actions, signed with the project's dedicated key, and verified for APK signature and package metadata. Checksums are in `SHA256SUMS.txt`. Package ID: `io.github.clcty.arcana_notes`. Future updates will keep the same signing identity.

Validation includes 21 Flutter tests, two local web relay tests and static analysis. Android device testing has not been performed. Wallpaper colors require platform support. AI requires your own API key and may incur charges; OpenCode Go availability and permitted usage depend on the provider. Journal data is local and is removed when app data is cleared or the app is uninstalled. Tarot interpretations are reflection prompts, not guaranteed predictions.
